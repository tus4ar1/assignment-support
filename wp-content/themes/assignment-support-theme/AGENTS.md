# Assignment Support WordPress Theme

## Project Goal

Build a fast, professional and responsive WordPress website for an ethical
academic-support business.

The website should generate enquiries through a short form, WhatsApp and email.
It must present services as tutoring, academic guidance, editing, proofreading,
referencing support, research guidance and data-analysis assistance.

## Technology

- Use WordPress, PHP, semantic HTML, CSS and minimal JavaScript.
- Build a custom WordPress theme.
- Do not use Elementor or another page builder.
- Use WordPress functions for URLs, menus, assets and dynamic content.
- Keep business functionality separate from the theme.
- Use a plugin or shortcode for enquiry-form processing.
- Do not edit WordPress core files.
- Do not add unnecessary JavaScript libraries.

## Landing Page Structure

Build the homepage sections in this order:

1. Announcement bar
2. Header and navigation
3. Hero section with a short enquiry form
4. Trust indicators
5. Student problems and solutions
6. Academic-support services
7. How the service works
8. Reasons to choose the business
9. Subjects and software supported
10. Specialist profiles
11. Learning resources and samples
12. Genuine testimonials
13. Pricing information
14. Academic-integrity policy
15. Frequently asked questions
16. Final call to action
17. Footer

## Primary Call to Action

Use one primary call to action throughout the website:

“Get a Free Support Plan”

Use WhatsApp as a secondary action.

## Design Requirements

- Use a professional educational appearance.
- Use navy, blue, teal, white and light-grey colours.
- Maintain a maximum content width of 1200px.
- Use one consistent primary button style.
- Use clear typography and generous white space.
- Avoid sliders and unnecessary animation.
- Avoid intrusive pop-ups.
- Make the design fully responsive.
- Prioritise mobile visitors.
- Use a sticky header where appropriate.
- Maintain accessible colour contrast.
- Provide visible keyboard focus states.

## Content Requirements

- Use clear British English.
- Keep paragraphs concise.
- Use benefit-focused headings.
- Do not guarantee grades.
- Do not advertise examination impersonation.
- Do not encourage students to submit purchased work as their own.
- Do not invent reviews, statistics or expert qualifications.
- Use clearly labelled placeholders where information is unavailable.
- Do not claim associations with universities without evidence.
- Include an academic-integrity statement.
- Describe samples as learning resources only.

## WordPress Requirements

- Add support for title-tag, custom-logo and post-thumbnails.
- Register primary and footer navigation menus.
- Enqueue stylesheets and scripts through WordPress functions.
- Escape all dynamic output.
- Sanitise all user input.
- Use nonces for custom forms or state-changing requests.
- Make text, links and images editable where reasonably practical.
- Use template parts for individual homepage sections.
- Follow WordPress template hierarchy.
- Keep functions.php small and organised.

## SEO Requirements

- Use one H1 on each page.
- Maintain a logical H2 and H3 hierarchy.
- Use descriptive page titles and metadata.
- Use meaningful link text.
- Add alternative text to informative images.
- Avoid keyword stuffing.
- Avoid duplicating country landing-page content.
- Use clean internal linking.
- Optimise images before loading them.

## Performance Requirements

- Prefer WebP or similarly efficient images.
- Lazy-load below-the-fold images.
- Avoid render-blocking assets where possible.
- Minimise JavaScript.
- Prevent unnecessary plugin dependencies.
- Use responsive image sizes.

## Validation

After material changes:

- Check PHP syntax.
- Check for escaping and sanitisation issues.
- Check desktop, tablet and mobile layouts.
- Check keyboard navigation.
- Check heading hierarchy.
- Check links and buttons.
- Check browser-console errors.
- Report remaining placeholders.
- Explain what was changed.
